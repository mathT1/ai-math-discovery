# 기기 점검표 · 현장 시연 절차

> 대상: 동규 선생님(요청자)과 동료 교사 · M4 (FINAL_PLAN 8절 "기기 점검은 교사·동료 교사가 직접")
> 사이트: https://matht1.github.io/ai-math-discovery/
> 점검이 끝나면 맨 아래 **결과 기록** 표를 채워 Claude에게 알려 주세요. 문제가 있으면 "기기 · 브라우저 · 몇 번 단계 · 화면 사진"만 주시면 됩니다.

---

## 1. 점검할 기기 (있는 것만)

| 기기 | 브라우저 | 우선순위 |
|---|---|---|
| 교실·교무실 PC (윈도우) | 크롬 또는 엣지, 웨일 | ★★★ 시연·채점 |
| 시연용 노트북 | 크롬 또는 엣지 | ★★★ 현장 시연 |
| 크롬북 (학교 관리 기기) | 크롬 | ★★ 학생 활동 |
| 아이패드 | 사파리 | ★★ 학생 활동 |
| 안드로이드 태블릿·학생 스마트폰 | 크롬, 삼성 인터넷 | ★ |

## 2. 기기마다 확인할 것 (10~15분)

### A. 학생 활동

| # | 할 일 | 확인 |
|---|---|---|
| A1 | 홈을 열면 활동 카드 2개가 보인다 | ☐ |
| A2 | [세 점이 한 직선 위에…] → [탐구 활동]: 손가락·마우스로 점이 찍히고, 다시 누르면 지워진다 | ☐ |
| A3 | (0,0), (2,1), (4,2)를 찍으면 점선·네모·'!'·기울기 1/2 목록이 나온다 | ☐ |
| A4 | 분수·수식이 깨지지 않고 수식 모양으로 보인다 | ☐ |
| A5 | [곱셈 한 번을 줄여라] → 숫자 칸에 숫자 키패드가 뜨고, +/−/· 선택 상자가 눌린다 | ☐ |
| A6 | 화면을 세로·가로로 돌려도 옆으로 잘리지 않는다 | ☐ |

### B. 제출 (학교에서 쓰는 방법만)

| # | 할 일 | 확인 |
|---|---|---|
| B1 | [결과물 제출] → 반·번호·이름 → **① 보고서 저장(PNG)**, **② 제출 파일 저장(JSON)**: 파일이 어디에 저장되는지 확인 (아이패드: 파일 앱 › 다운로드) | ☐ |
| B2 | 구글 클래스룸 과제에 B1의 두 파일을 올릴 수 있다 | ☐ |
| B3 | 패들릿: [② 제출 코드 복사] → 패들릿 게시물에 붙여 넣기가 된다 | ☐ |
| B4 | 출력물: [인쇄하기] → 인쇄 미리보기에 보고서 한 장이 나온다 (교사 채점란 포함) | ☐ |
| B5 | 탭을 닫았다 다시 열면 오늘 한 활동이 남아 있다 (이름은 남지 않음) | ☐ |

### C. 교사 채점 (PC에서)

| # | 할 일 | 확인 |
|---|---|---|
| C1 | [교사용 평가 페이지] → 모듈 선택 → B1의 JSON을 끌어다 놓으면 한 줄이 생긴다 | ☐ |
| C2 | B3의 패들릿 게시물 내용을 통째로 복사해 [코드 읽기]에 붙이면 한 줄이 생긴다 | ☐ |
| C3 | [샘플 학급 불러오기] → 30명이 나오고, 1~20번은 교사 점수까지 채워져 있다 (21~30번은 직접 채점해 보기) | ☐ |
| C4 | [CSV 내려받기] → 엑셀에서 열었을 때 한글이 깨지지 않는다 | ☐ |

### D. 인터넷 없이 (시연 노트북은 꼭)

| # | 할 일 | 확인 |
|---|---|---|
| D1 | 인터넷이 될 때 홈을 연다 → 맨 아래에 **"✔ 인터넷 없이 쓸 준비 완료"**가 나올 때까지 기다린다 (보통 몇 초) | ☐ |
| D2 | 와이파이를 끄거나 랜선을 뺀다 | ☐ |
| D3 | 같은 브라우저로 홈 → 두 활동 → 제출(PNG·JSON 저장) → 교사 페이지 → 샘플 불러오기 → CSV 가 모두 된다 | ☐ |
| D4 | 지도안 보기도 열린다 | ☐ |

**주의**
- **시크릿(InPrivate) 창에서는 미리 저장되지 않습니다.** 일반 창을 쓰세요.
- 브라우저의 "인터넷 사용 기록·캐시 삭제"를 하면 저장한 것이 지워집니다. 다시 D1부터 하면 됩니다.
- 학교 관리 크롬북은 관리 정책 때문에 다운로드나 오프라인 저장이 막혀 있을 수 있습니다. 막혀 있으면 B1, D1 결과를 그대로 적어 주세요(정보부에 문의할 내용을 정리해 드리겠습니다).
- 사이트가 고쳐지면 화면 아래에 "새 버전이 있습니다 [새로고침]"이 뜹니다. 하던 일을 마친 뒤 누르면 됩니다(채점 중이면 CSV를 먼저 저장).

## 3. 현장 시연 절차 (교육자료전)

**전날**
1. 시연 노트북으로 사이트를 열고 D1 "준비 완료"를 확인합니다.
2. 와이파이를 끄고 아래 시연 순서를 한 번 끝까지 해 봅니다(리허설).
3. 노트북 브라우저 데이터를 지우지 않습니다.

**시연 순서 (약 7분)**

| 순서 | 화면 | 보여 줄 것 |
|---|---|---|
| 1 | 홈 | 활동 카드, 과목·단원 필터, "학생 정보는 어디에도 전송되지 않습니다" |
| 2 | 세 점이 한 직선 위에… → 탐구 | 4×4에서 점 찍기 → 공선 표시 → 힌트 |
| 3 | AI와 비교 | 경우의 수 표, 연구 결과(고전 방법 19×19 vs AI) |
| 4 | 곱셈 한 번을 줄여라 → 탐구 3번 | 블록 부호 고르기 → 지워진 항 → "곱셈 7번 · 덧셈·뺄셈 18번" |
| 5 | AI와 비교 | 4×4 47번과 **mod 2 주의** |
| 6 | 결과물 제출 | 제출 방법 4가지, PNG 보고서 저장 |
| 7 | 교사용 평가 페이지 | [샘플 학급 불러오기] → 자동 점수·근거(마우스 올리기) → 교사 점수 고르기 → 성취수준 → CSV |

**만약을 위한 대비**
- 오프라인 저장이 안 되어 있으면: 휴대전화 테더링으로 접속합니다.
- 화면이 이상하면(인터넷 필요): 홈 주소 끝에 `?nosw`를 붙여 열고 한 번 더 새로고침하면, 저장한 것을 지우고 새로 받습니다. 그다음 다시 D1을 합니다.
