**FINAL_PLAN에서 바꾼 점** (DISCUSSION_LOG 15절)
- 난이도: "빈칸 채우기 / 직접 조합" → **안내**(쓸 블록만 열림, 부호만 정하기) / **도전**(7개 블록 모두 열림). 점수는 같고, 교사 화면 근거에 "안내 모드"만 표시합니다.
- 곱셈 7번 항목: `multiplications` 대신 `strassenOK`(네 성분 모두 정답)를 씁니다. M₁~M₇은 서로 독립이라 네 성분이 맞으면 곱셈은 반드시 7번입니다. 계수 3⁷가지를 전수 검사해 확인했습니다(FACT_SOURCES M15).
- **M4(2×2 최소 7번, Winograd 1971)**: 서지는 Crossref로 확인했습니다. 본문은 유료라 읽지 못해 **⚠️를 유지**합니다. 화면에는 "7번보다 줄일 수 없다고 알려져 있습니다"로만 쓰고, 테스트가 "최소임이 증명" 문구를 막습니다. FINAL_PLAN 7-2의 "증명되어 있음" 표현보다 약하게 쓴 것입니다.
- 새 사실 M13~M15를 FACT_SOURCES에 추가했습니다(모두 🔁 직접 계산).

**Claude가 확인한 것**
- 단위 테스트 49/49 통과 (matrix-mult 17개)
  - 네 성분을 16칸 계수 표로 전개하면 정의와 같음
  - 덧셈·뺄셈 18 = 블록 안 10 + 잇기 8
  - 무작위 정수 200쌍에서 숫자 검산
  - 숫자만 우연히 맞는 조합(A = B = O)은 오답 처리
- 종단 테스트 26항목 통과: 정의대로 오답 표시 → 워밍업 → 안내 잠금 → 4성분 완성(곱셈 7, 덧셈·뺄셈 18) → 도전 전환 → AI 비교 → 제출 4가지 → 교사 채점 → CSV
- 기존 두 모듈의 종단 테스트도 다시 통과
- 1200px·390px 화면과 PNG 보고서를 눈으로 확인했고, 가로 넘침은 없었습니다.

## 2. 검토해 주실 것

### ① 수학 정확성 (가장 중요)
- `algebra.js`: `STRASSEN` 7개 블록(특히 M4, M6의 `text`와 계수가 맞는지), `TARGET_TERMS`, `combine`, `cancelledTerms`, `countAdds`
- `guide.md` 5절 정답표: 각 성분에서 지워지는 항 목록
- [AI와 비교] 2절
  - N³과 7ᵏ 비교표와 "a는 늘 왼쪽, b는 늘 오른쪽이라 성분이 행렬이어도 성립"(M13) 설명이 맞는지
  - 고1에게 적절한지

### ② 내용·표현
- 화면과 `guide.md`의 문장이 FACT_SOURCES 범위 안에 있는지. 특히 다음 두 가지를 봐 주세요.
  - **M4 ⚠️** 표현 수준
  - **mod 2** 설명: "모든 수를 2로 나눈 나머지(0 또는 1)로만 계산, 1 + 1 = 0", "보통의 수 계산에서도 47번이 된다는 뜻은 아님"
- `data/paper.json`: 4×4 "1969년 이후 처음으로 줄임"(M6), 5×5 일반 계산 98 → 98(M7)
- AlphaZero를 "바둑·체스를 스스로 익힌 AI"로 소개 (논문 참고문헌 1: "masters chess, shogi, and Go")
- 금지 문장이 없는지, 고1 용어 수준인지 (R7: 텐서·랭크는 쓰지 않음)
- 가능하면 Winograd(1971) 본문이나 믿을 만한 2차 문헌을 찾아 주세요. 확인되면 M4를 ✅로 올리겠습니다.

### ③ 평가
- 정답 성분 구간(4→30, 3→22, 2→15, 1→7)과 `strassenOK` 10점
- **안내 모드와 도전 모드의 점수가 같은 것**에 동의하시는지. 다른 안(예: 안내 모드는 `seven` 항목 0점)이 있으면 제안해 주세요.
- Q1·Q2 levels 문구

### ④ 수업 흐름 (`guide.md` 1절)

- 워밍업(ac − bd, ad + bc)이 본 활동으로 잘 이어지는지

- 계수 선택 상자 28개를 키보드와 화면낭독기로 쓸 수 있는지 (각 상자는 "c₁₁ 만들기: M1 앞의 부호" 같은 이름을 가짐)
