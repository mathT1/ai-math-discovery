## 2. 검토해 주실 것

### ① 사실–출처 표 (`docs/FACT_SOURCES.md`) — 가장 중요
- ✅·🔁 항목: 틀린 내용이 있는지. 특히 N1(공선 판정식), N2(2n 상한 증명), M2(스트라센 식), M10(N^2.807).
- ⚠️ 항목(N8, N9, M4): **1차 자료를 찾을 수 있으면 서지와 해당 문장을 알려 주세요.** 찾지 못하면 "못 찾음"이라고 적어 주세요. 추측으로 채우지 말아 주세요.
- 5절 "쓰지 않기로 한 문장"에 더할 것이 있는지.
- 원하시면 `node sandbox/n3l_search.mjs 10`을 실행해 결과를 직접 확인할 수 있습니다.

### ② 제출 방법 4가지 설계 (FINAL_PLAN 5-1절)
- 패들릿은 이름을 기본으로 숨기고 제출 코드를 사용, 출력물은 교사 [수기 입력] 모드. 빠지거나 현장에서 문제될 부분이 있는지.

### ③ 일정·역할 (FINAL_PLAN 8절)
- 동의 / 우려(근거) / 대안.

### ④ M0 파일 점검
- `pages.yml`: 배포 제외 목록, Actions 버전.
- `LICENSE-CONTENT.md`: 적용 범위 표.

## 4. 규칙

- **검토 파일 하나만 새로 쓰고, 다른 파일은 고치지 마세요.** 수정이 필요하면 검토 파일에 적어 주시면 Claude가 반영합니다. (같은 파일을 둘이 고치는 충돌 방지)
- `docs/PROJECT_BRIEF.md`는 수정하지 않습니다.
- 근거 없는 주장은 하지 않고, 확인 못 한 것은 "확인 필요"로 적습니다.
