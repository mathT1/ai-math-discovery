# [견본] 교사용 지도안

> 새 모듈을 만들 때 이 형식을 따릅니다. 아래 다섯 부분은 모두 필수입니다.

## 1. 차시 흐름

| 단계 | 시간 | 활동 | 발문 |
|---|---|---|---|
| 도입 | 5분 | 1부터 100까지의 합 묻기 | "하나씩 더하지 않고 구할 수 있을까?" |
| 탐구 | 20분 | n을 바꿔 가며 합 구하기 | "n이 홀수일 때도 같은 방법이 될까?" |
| 비교 | 10분 | 짝짓기 방법과 비교 | |
| 정리 | 10분 | 정리 질문, 결과물 제출 | |

## 2. 학습 목표

- 1부터 n까지의 합을 $\dfrac{n(n+1)}{2}$로 구할 수 있다.

## 3. 예상 오개념

- n이 홀수이면 짝이 맞지 않는다고 생각함 → 같은 수열을 거꾸로 써서 두 줄을 더하는 방법으로 안내

## 4. 평가

- 자동: 합 계산 (원자료 n, 답으로 다시 계산)
- 교사: 방법 설명 (rubric.json의 levels 참고)

## 5. 사실–출처 표

| 사실 | 출처 |
|---|---|
| $1+2+\cdots+n = \dfrac{n(n+1)}{2}$ | 교과 내용 (수열의 합) |
